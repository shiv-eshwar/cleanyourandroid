# Security reporting

Use [GitHub private vulnerability reporting](https://github.com/shiv-eshwar/cleanyourandroid/security/advisories/new) for issues that could expose phone data, bypass approval, target a different device, or cause unintended deletion or changes.

Include the affected version, connection type, expected and observed behavior, and the smallest safe reproduction. Use synthetic files or a fake device when practical. Keep personal data, pairing codes, credentials, and full phone logs out of the report. Use the public issue tracker for ordinary bugs and device compatibility reports.
